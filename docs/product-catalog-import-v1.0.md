# 东航产品目录导入说明 v1.0

## 数据来源

`docs/klg.xlsx` 是产品知识文档切分结果，包含产品名称、产品描述、产品须知、权益特点和服务限制等内容。导入程序按文档名中的产品编码合并同一产品的全部段落，过滤“产品一览”等无明确产品编码的总览问答内容。

## 平台映射

每个产品写入当前租户的产品包目录：产品编码形成 `external_id`，产品名称写入名称，产品描述和权益特点写入描述，产品提示、购买资格、退改及使用限制写入适用条件。产品初始状态为“草稿”，需业务人员审核后再在营销活动中引用。

当前 `CEA-HQ` 租户已导入 19 个产品包，覆盖 Wi-Fi、里程、行李、贵宾室、国博、低碳、C919、助农、安心和团队出行等航空营销产品。

## 幂等执行

默认按“租户 + 产品编码”去重，重复执行不会创建重复产品；使用 `--upsert` 可同步更新已有产品内容。

```powershell
python services/platform-api/scripts/import_product_catalog_v1.py
python services/platform-api/scripts/import_product_catalog_v1.py --upsert
```

## 业务使用

活动人员可以在产品管理页面查看、编辑、审批产品包，活动编排时引用已审核的产品包；产品须知和限制可供内容生成、合规校验及产品匹配智能域读取，但不会自动绕过人工审批。
