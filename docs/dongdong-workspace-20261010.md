# 东东工作空间与模型配置（2026-10-10）

## 交付行为

- Token Plan 设为默认服务，模型 `qwen3.8-flash`，超时 180 秒，最大输出 8192 Token。百炼工作空间保留原有密钥，使用同一对话模型。密钥只存服务端加密字段，不进入代码、文档、对话或 Git。
- 两个 OpenAI 兼容地址分别用于对话和模型发现。用户提供的百炼 `/api/v1/agentstudio` 地址属于 AgentStudio 服务入口，不拼接 `/chat/completions`。
- 模型页面采用厂商列表与配置表单，带本地厂商 Logo；模型使用下拉选择，可用模型、用量、自定义标识使用弹窗，高级参数折叠。模型检测实际验证流式对话和只读 MCP 工具调用。
- 首页和浮动东东共用一个工作空间，提供新对话、历史对话、任务记录和偏好记忆。对话标题压缩到两行，任务参数和执行结果折叠展示。
- 历史由服务端持久化，按用户和租户隔离；最近 12 条完成消息、最多 30 条明确保存的偏好进入新一轮上下文。当前会话最近任务状态从后台读取，优先于历史描述。记忆可查看、添加和删除，拒绝密钥和密码。
- 东东查询授权业务 API，动态读取真实路由、参数及 JSON Schema。业务修改先生成待确认卡片，确认时调用原业务端点，重新执行角色、租户、事实与审批校验；重复确认返回 409。
- 六个智能域、活动、客群、产品、内容、审批、渠道、知识本体和数据处理等能力通过统一接口接入。文件上传、模型密钥和账号密码使用工作台导航卡片进入专用表单。
- 后台统计生成六类柱图：活动阶段、机会状态、客群包规模、产品状态、内容渠道、渠道送达；可切换数据表和导出 CSV。客群包未去重不作为独立旅客总数，缺少交易归因不推算收入或 ROI。
- 活动红色计数及编号生命周期条已移除。保留必要的业务状态、错误和数据口径。

## 未回复修复

旧 MCP 工具没有声明只读，AgentScope 在确认事件挂起；适配器仅读取文本增量，遗漏最终消息和失败结束事件。现为真正只读的 MCP 工具注册 `readOnlyHint`，收集最终消息和文本块结束事件，并明确处理挂起确认、轮数耗尽、中断及空正文。私有任务提案和偏好存储不执行业务变更，使用内部授权；实际业务仍在任务确认后执行。执行过程不暴露模型私有思考，也不逐 Token 添加过程行。

异步机会洞察提交后显示执行中；查询任务历史和对话时同步后台状态，打开的任务卡片每 5 秒更新，失败显示实际错误。

## 验证证据

- 全量 API 回归原 113 项通过，新增异步任务状态和六智能域任务桥接测试后，相关助手测试 7 项通过；最终全量由部署 CI 再验证。
- 流式客户端 5 项测试通过；所有浏览器 JavaScript 语法、生产文案、Docker 静态资源及 diff 空白校验通过。
- 两套真实服务均通过模型、流式与本体工具检测。本地 Token Plan 对话可查询产品、内容、审批、渠道、本体、处理任务和智能域历史。
- 真实对话分别生成活动、客群包、产品包、App 素材待确认卡片；确认后记录写入业务后台，任务历史显示完成。
- 真实对话生成六个智能域待确认卡片，逐项确认后均为 `needs_approval`，未接受结果、未发布活动。
- 浏览器验证跨新对话召回偏好、历史图表恢复、图表/数据切换、CSV 导出和任务历史最新状态。
- 自动化覆盖用户/租户隔离、客户端伪造历史不生效、重复执行阻断、参数校验、记忆凭据拒绝、后台统计一致、模型发现更换地址不复用已存密钥。

新增四张助手表由现有启动建表流程创建，schema 版本为 `20261010.1`。生产数据库卷和既有模型配置在部署时保留。
