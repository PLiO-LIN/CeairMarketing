# NDC 24.1 模拟接口与平台接入 v1.0

## 目标

本模块提供一组完全虚构的 NDC 24.1 航班销售接口样例，用于联调东航智能营销平台的航班、运价、产品包和辅营产品数据处理流程。字段结构参考 NDC 24.1 文档，接口不会访问真实生产系统，也不包含旅客隐私、账号、Token 或生产密钥。

## 接口

- `POST /api/ndc/mock/air-shopping`：按出发机场、到达机场和出发日期返回模拟航班查询报文。
- `POST /api/ndc/mock/best-pricing`：返回包含最低含税价、航班、产品编码和库存的模拟最优报价。
- `POST /api/ndc/mock/order-list`：返回虚构订单列表，用于订单状态和营销转化联调。
- `POST /api/ndc/mock/sync-flight-products`：将模拟航班产品响应送入现有数据处理智能体，生成候选对象和关系，并停留在人工确认节点。

## 处理链路

NDC 模拟响应经过航班产品标准化适配器，抽取机场、航线、航班、航段、舱位、运价、基础产品、产品标签、产品组和辅营产品，并生成 `operates_on`、`has_segment`、`has_cabin`、`has_fare`、`uses_product`、`includes_ancillary` 等关系。数据处理任务会记录接收、标准化、语义校验和人工确认等阶段，营销人员确认后才允许写入正式本体，避免把不可靠的接口数据直接进入知识底座。

## 示例请求

```json
{
  "origin": "SHA",
  "destination": "SYX",
  "departure_date": "2026-09-14",
  "sales_channel": "10000"
}
```

## 联调说明

接口适合本地开发、测试环境和演示环境使用。后续切换真实 NDC 供应商时，应通过数据源配置替换 endpoint，并保留版本、渠道、请求 ID、响应摘要、处理任务和人工确认记录；不要将真实生产凭证写入仓库或前端代码。
