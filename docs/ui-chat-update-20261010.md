# 2026-10-10 页面与对话更新

- 首页与浮动东东共用租户授权的流式对话接口。发送按钮、回车、快捷问题调用同一通道，成功答复后刷新业务列表。
- 后端增加 SSE 心跳与最长等待限制；前端明确处理断流、超时、错误、登录失效，并提供停止等待、重试与业务列表刷新。
- 演示模型读取当前后台活动名称、状态和规模，明确标注受控模型；真实模型仍通过原 AgentScope 工具与租户权限运行。
- 页面删除标题副文案与重复介绍，统一字体；侧栏一级与二级目录均为 14px，分组支持键盘操作、折叠和状态保存。
- 动态画像、需求信号、触达策略、交易归因、本体链路及对话依据改为详情弹窗；内容生成配置及次要操作改为弹窗。视觉库仅在渠道预览展示。
- 东东使用东航蓝红配色的本地 SVG 机器人。
