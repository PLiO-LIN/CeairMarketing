## 2. 本地启动与停止

在项目根目录打开 PowerShell：

```powershell
docker compose up -d
docker compose ps
```

查看服务日志：

```powershell
docker compose logs -f api
docker compose logs -f web
```

停止服务但保留数据库数据：

```powershell
docker compose stop
```

更新前端或后端代码后，重新构建并启动：

```powershell
docker compose up -d --build
```

不要随意执行带 `-v` 的 `docker compose down`，该操作会删除本地数据库卷。

## 4. 如何使用模型

1. 打开 `http://localhost:8088/` 并登录平台。
2. 点击右下角带机器人图标的“营销助手”。
3. 输入营销问题，例如“当前有哪些高价值营销机会？”。
4. 点击发送，或按 Enter 发送；Shift + Enter 可换行。
5. 对话中的“执行过程”会显示加载上下文、调用大模型和生成答复等步骤。

网页调用路径为 `POST /api/agent-chat/stream`。后端会从当前租户选择默认且已启用的模型，不会把 API Key 返回给浏览器。

## 6. 本次排查结论

营销助手按钮曾未显示，原因不是百炼配置错误：Docker 中运行的是旧版网页镜像，其旧版 `production.js` 不包含营销助手功能；本地最新代码已有该功能。

重新构建网页时还发现 `apps/web-v32/docker-entrypoint-auth.sh` 使用 Windows 的 CRLF 换行符。Linux 容器会因此无法识别脚本解释器并报退出码 127。该文件现已转换为 LF 换行符，网页容器可正常启动。
