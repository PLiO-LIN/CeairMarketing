# EG-CHPN 模拟实验报告

## 实验边界

本实验是机制验证，不是真实东航经营实验。数据由脚本生成，真实增量效应、证据质量和本体关系均由模拟器定义；结果不能写成真实订单、收入或转化提升。

## 设计

- 5 个随机种子：13、29、41、53、67；
- 每个种子 1800 个聚合客群，按第 63 天做时间切分；
- 训练窗口为 0 至 62 天，测试窗口为 63 至 89 天；
- 航线、产品和证据质量只出现在本体上下文节点，不出现在客群直接特征中；
- 比较随机可行策略、响应模型、表格 T-learner、无证据门的图模型和 EG-CHPN 图证据门模型；
- 主要指标为策略价值、策略相对随机提升、uplift RMSE、Top-k 真增量和非法动作选择率；
- 置信区间是 5 个随机种子均值的 1.96 × 样本标准差 / sqrt(5)，不是线上用户级置信区间。

## 结果

| 方法 | 策略价值均值 | 95% CI 半宽 | uplift RMSE | Top-k 真增量 | 非法选择率 |
|---|---:|---:|---:|---:|---:|
| EG-CHPN 图证据门 | 11203.879 | ±257.240 | 0.1840 | 1.0474 | 0.000 |
| 无证据门图模型 | 5863.456 | ±613.547 | 0.1553 | 1.0866 | 0.344 |
| 随机可行策略 | 9533.270 | ±351.456 | 1.3324 | 0.8927 | 0.000 |
| 响应模型 | 10658.859 | ±316.817 | 0.6409 | 0.9969 | 0.000 |
| 表格 T-learner | 10664.763 | ±272.162 | 0.2119 | 0.9975 | 0.000 |

在这个模拟机制中，EG-CHPN 的策略价值比表格 T-learner 高约 5.1%，并保持非法选择率为 0；去掉证据门后，非法选择率升至 34.4%。这个差异只说明“证据门和图上下文在预设机制下有效”，不说明真实航司业务一定有同样提升。

## 可复现命令

```powershell
cd services/platform-api
python -B scripts/run_eg_chpn_simulation.py
python -B scripts/verify_eg_chpn_simulation.py
```

实验原始数据、汇总结果和表格分别为 `eg-chpn-simulation-v1.0.csv`、`eg-chpn-simulation-v1.0.json` 和 `eg-chpn-simulation-table-v1.0.md`。投稿前必须用真实脱敏活动数据替换模拟数据，并补充基线实现、bootstrap 用户级置信区间、统计显著性和跨时间外推验证。
