# v3.17 竞赛演示手卡

## 启动与重放

```powershell
.\start-competition.ps1 -NewRehearsal -ApiPort 8804 -WebPort 8784
```

若端口已有排练服务，请选择一对空闲端口。登录 `competition / Competition@2026`，工作区选择“竞赛演示（虚构数据）”。固定业务日期为 **2026-09-18 10:00（北京时间）**；信号观测窗口与业务日期属于模拟场景，入库和人工操作时间按实际系统时钟显示。

每次新排练生成独立 SQLite 文件。重复启动按稳定外部 ID 补齐缺失对象，不覆盖已执行或已归档状态。已有业务环境默认不注入虚构数据。

## 推荐六分钟主线

| 环节 | 操作 | 说明 |
|---|---|---|
| 首页 | 展示定位、98 个画像字段、4 个营销活动、7 条预置运行记录、本体数量 | “旅客画像驱动闭环，需求可解释，决策可追溯”。运行和本体数量会随人工操作增加；通过“营销驾驶舱 → 营销总览”查看活动链路。 |
| 机会 | 搜索、酒店、攻略、SHA-SYX 经营窗口，展开评分依据 | 四项权重对应 96/92/88/86 分，加权91.9，四舍五入92；用于规则展示，不代表预测准确率。 |
| 客群 | 地域、偏好、种草—比价—决策时间线，51200→42000→36930→36420漏斗 | 近7天搜索>=2次；已出票、未授权和营销疲劳保护排除。偏好比例可交叉，客群包规模合计未去重。 |
| 智能体 | 总览六域协作区查看样例或输入要求运行 | 展示输入依据、结构化输出、治理和逐步 Trace；真实模型、受控模型、规则降级分别标注。 |
| 内容 | 预览 App/微信，打开视觉编辑，保存草稿 | 可编辑 SVG 视觉模板，非真实图像生成模型；另存为待审核草稿，已提交版本保留。经理或管理员可审核内容。 |
| 审批执行 | 主案例 V3 审批→执行联调→效果复盘 | 冻结客群、已审批产品、逐渠道审核内容、预算缺一不可。新内容草稿不会替换已提交 V3。 |
| 本体 | 知识中心→本体实例→选择主案例 | 展开来源文档、知识片段、信号、证据、智能体候选、人工决策、执行和复盘。 |

## 四类案例

- 上海—三亚国庆早鸟：主线 V3 待审批，App与微信均有已审核内容。
- 上海—成都行李优享：执行中，App回执正常、短信失败；展示异常处理依据。
- 会员秋季出游唤醒：已完成，可查看渠道复盘与待交易归因状态。
- 三亚产品资格待核验：产品草稿、内容待审核、审批已退回；展示门禁阻断。

六域预置样例是完整的流程记录，不冒充真实模型推理。客群圈选受控样例只覆盖三亚搜索条件，其他要求需真实模型或人工配置；结果规模等待上游计算。策略首触/补触展示逻辑依据，实际联调按渠道任务分配，并不执行真实旅客响应调度。

## 标准接口

| 接口 | 用途 |
|---|---|
| GET /api/competition/demo | 模拟日期、画像、信号、评分和渠道策略；其他租户返回 enabled=false |
| GET /api/campaigns/{id}/readiness?version_id=... | 对指定活动版本校验审批前置条件 |
| POST /api/content-assets/{id}/review | 内容通过/退回与人工决策记录 |
| POST /api/agent-runs/{id}/accept | 人工确认候选为草稿，重复请求返回相同对象 |
| GET /api/campaigns/{id}/graph | 聚焦业务链路，避免其他活动经共享渠道混入 |
| POST /api/integrations/profile/audiences | 聚合客群标准同步；字段注册、租户隔离、重复导入检查 |
| POST /api/integrations/products/packages | 产品包同步；有效期校验与批次原子性 |

接口导入文件位于 docs/examples/competition-audiences.json 与 competition-products.json。数据接入记录展示成功、重复未变化与校验失败样例。

实际画像、实时库存价格、真实渠道发送、订单收入、去重客户键和归因基线仍等待上游接入。未取得交易依据时收入和ROI保持“待交易归因”。
