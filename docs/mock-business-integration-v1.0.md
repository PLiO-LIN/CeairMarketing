# 模拟业务接口与数据边界 v1.0

当前阶段不连接东航真实生产系统，平台使用统一的模拟业务服务完成开发、演示和联调。所有响应带有 source=ceair-mock-business-v1，避免将伪造数据误认为生产数据。

## 接口

- GET /api/mock/flight-operations：返回航线、航班、机型、舱位库存、客座率、正常率、票价和机上 Wi-Fi 等经营样例。
- GET /api/mock/profile-summary：返回 ToB/ToC 客群规模、画像摘要、偏好航线、会员等级和可用画像维度。
- GET /api/mock/market-signals：返回节假日、航线经营和辅营需求等市场信号，供机会洞察使用。
- GET /api/mock/product-catalog：返回 Wi-Fi、里程、行李、低碳和 C919 等产品样例。
- POST /api/mock/channels/{channel}/deliver：模拟 App、短信、微信等渠道发送，并返回送达、点击和转化估算。

## 使用约束

模拟接口只用于开发、测试和比赛演示，不代表东航实时业务数据。接口调用需要当前登录用户和租户权限；发送接口需要写权限。后续对接真实系统时，保持同样的数据结构，在适配器层替换实现，不改变活动、智能域和复盘模块的业务接口。

## 业务闭环

模拟航班经营 + 模拟画像 + 模拟市场信号 → 机会洞察 → 客群洞察 → 产品匹配 → 活动编排与内容生成 → 审批 → 模拟渠道触达 → 模拟回执和转化 → 效果分析
