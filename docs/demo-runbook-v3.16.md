# v3.16 竞赛演示手卡

目标：用一个航空营销案例，展示用户画像如何成为可确认、可审批、可追溯的业务决策。主案例为“上海—三亚国庆早鸟”，画像人数、信号与渠道回执均为虚构数据，受控测试模型用于验证流程。真实经营收益、实时库存和跨渠道旅客归因尚未接入。

## 现场准备

安装依赖后，在工程根目录运行：

```powershell
.\start-competition.ps1 -NewRehearsal -ApiPort 8803 -WebPort 8783
```

- 页面：`http://127.0.0.1:8783/`；API 文档：`http://127.0.0.1:8803/docs`。
- 本地账号：`competition` / `Competition@2026`；工作区选“竞赛演示（虚构数据）”。
- 脚本输出新的排练数据库路径；旧数据库不会删除。新库的预置案例停在待审批阶段。
- 默认启动 `.\start-competition.ps1` 仍使用 8781 / 8801 和持久数据库；已演示完的状态不会自动重置。
- 每次新排练使用一对空闲端口，例如 8804 / 8784。占用端口会明确报错，避免误用上次的数据服务。
- 页面图标、关系图、品牌素材均为本地资源。主线不需要外网；外部热点实时采集、外部模型和 MinerU 不纳入必演步骤。
- 开场前检查首页、画像字段、待审批任务各能打开一次，浏览器缩放 100%。建议桌面展示，讲解时收起无关窗口。

## 六分钟主线

| 时间 | 操作 | 讲解重点 |
| --- | --- | --- |
| 0:00-0:30 | 首页 → 进入营销总览 | “从画像到营销决策，最终决策由业务人员确认。”展示东航品牌与当前工作区。 |
| 0:30-1:30 | 客群画像 → 画像字段、客群包、圈选记录 | 区分字段口径、组合条件、冻结快照。查看“三亚高意向未购客群”和 36,420 人快照；明确虚构案例口径。 |
| 1:30-2:10 | 机会工作台 → 机会清单；产品与权益 → 活动产品包 | 说明三亚出游意向对应早鸟产品。产品来自目录，实际价格、库存和资格仍需上游核验。 |
| 2:10-3:10 | 内容工坊 → 选择主案例、客群、产品、App → 生成 → 确认并保存草稿 | 指令：“突出行李权益，不使用最低价表述”。展开业务依据，说明受控测试结果需要人工确认；只生成不自动保存。 |
| 3:10-4:10 | 审批与发布 → 预置 V3 待审批 → 查看关联依据 → 通过并进入执行 → 确认处理 | 审批引用冻结快照、产品版本和内容。新生成草稿独立保存，不会替换已经提交的 V3。只有审批通过才能生成执行批次。 |
| 4:10-5:10 | 执行监控 → 执行联调 → 渠道任务 → 选择 App | 展示状态变化、送达与失败。终态批次不能重复执行。统计是渠道任务与事件计数，不宣称去重旅客人数。 |
| 5:10-6:00 | 效果复盘 → 效果总览、转化归因 → 导出复盘报告；知识中心 → 本体实例 | 回执有虚构标注，漏斗使用一致分母。收入与 ROI 待交易归因；对象来源与关系帮助解释决策依据。导出为 JSON。 |

主案例使用预置 V3 走完闭环。不要在 6 分钟主线中修改已提交版本；若要执行新生成的内容，可另建活动草稿，关联快照、产品、内容与渠道，再提交审批。

## 追问时展示

- **标准接入**：客群画像 / 产品与权益 → 同步业务数据，分别导入 `docs/examples/competition-audiences.json`、`docs/examples/competition-products.json`。数据接入 → 处理记录查看来源与批次，再次导入展示未变化计数。接口字段见 [标准接口说明](competition-readiness-v3.15.md)。
- **新建活动**：活动中心 → 创建活动，勾选渠道并引用已有快照、产品、内容 → 保存草稿 → 查看 → 提交审批。版本详情显示北京时间。
- **内容维护**：新建内容可人工保存；关键词筛选即时生效。AI 结果确认后形成草稿，仍需业务审核。
- **租户治理**：权限与审计显示当前账号授权和最近业务处理记录。工作区切换重新加载数据；完整权限变更审计尚未提供。
- **来源追踪**：知识中心可查看本体结构、实例和文档。对象扩展属性展示入库记录，活动实时状态以活动中心、审批和执行页为准。

## 异常替代路径

| 现象 | 现场处理 |
| --- | --- |
| 页面加载失败或 API 未就绪 | 查看 `services/platform-api/competition-api-8803-error.log`，确认当前端口；重新运行启动脚本，不删除数据库。 |
| 进入了空工作区 | 在顶部选择“竞赛演示（虚构数据）”。 |
| 案例已经审批或执行过 | 新建排练环境，使用空闲端口；保留旧环境供对照。 |
| 外部模型或实时热点服务异常 | 使用当前竞赛流程验证模型与预置案例，说明外部接入状态。 |
| 现场生成结果不符合预期 | 查看已保存内容与生成任务记录，继续走预置 V3 审批主线。 |
| 未执行活动的复盘为空 | 切回主案例；先审批、再执行联调才产生回执。 |
