# 东航智能营销平台架构图集

使用 diagrams.net 或 draw.io 打开多页图集；各页面的节点、文字和折线均可编辑。独立 .drawio 文件与同名 SVG、PNG 一一对应。整体图按当前系统模块绘制；生产接口及算法扩展采用虚线并标注尚未接入或上线。

- 东方航空智能营销平台总体架构：overall.drawio
- 平台分层架构与跨层控制：architecture.drawio
- 数据来源到业务与本体的处理链路：dataflow.drawio
- 航空供给与营销本体关系：ontology.drawio
- 本体关系与业务资格共同约束行动：constraints.drawio
- 东东与业务智能域协作架构：agents.drawio
- 从自然语言提问到活动草稿的时序：sequence.drawio
- A2UI输出渲染与交互回传架构：a2ui.drawio
- 算法模型与本体约束的扩展架构：algorithm.drawio
