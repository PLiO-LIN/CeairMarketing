## 文档内容

正文覆盖数据来源登记、15份爬取CSV明细与哈希、29个入库数据集、字段和数据质量、本体类型关系与多跳资格约束、AgentScope运行与受控工具、A2UI数据绑定与公开过程事件、任务确认和事务、节假日营销七阶段案例、反事实关系实验、效果评估、算法扩展方案、权限与部署以及测试证据。

架构与流程图统一采用 draw.io 风格：总体架构、分层架构、数据链路、本体关系、业务资格约束、智能体协作、任务执行时序、A2UI交互以及算法扩展共9张。使用统一字体、浅色分组和正交连线；实线表示当前实现，虚线标明规划接口或算法扩展。源码仓库的 `docs/竞赛提交材料/drawio` 保留各张独立图源，`figures` 保留对应SVG和PNG。其余4张统计图保留图表形式。

技术基线为系统v3.19、代码提交124d2bdd3828，验证状态截至2026年10月13日。公开报价来源于项目已有爬取文件；原采集接口与captured_at未核验。客户、订单、库存、营销和实验为显式标记的模拟数据。429,996行含原始层、标准层和派生层，不能理解为独立旅客数。算法训练与真实渠道接入属于后续方案，不作为已完成成果。
