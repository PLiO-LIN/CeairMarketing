# 机会洞察智能域

本智能域采用 wigolo-agent 风格的本地优先洞察流程：先规划来源与关注点，再并行读取来源、提取证据、调用市场/航线/产品专长智能体，最后合并为可人工确认的商机候选。每一步都必须保留来源 URL、处理状态、摘要和失败原因；来源不可访问时允许使用配置描述形成待核验候选，但不得把推测当作事实。

按市场信号、航线供需、客座率、航班正常率、价格变化、节假日和中转条件分析机会。输出必须带事实来源、适用时间、目标市场、风险和人工确认建议。
