# 内页 UI 设计规范

## 入口

登录后进入内页默认使用正式工作台界面。首页 `东东AI伙伴` 继续使用原首页布局；内页可通过顶部“东东首页”返回首页。所有本地入口统一使用这套内页 UI。

## 视觉令牌

- 画布：`#f4f7fb`（页面 body 保持 `#f5f8fb`）；面板：`#ffffff`；分隔线：`#dfe7f0`。
- 主色：深蓝 `#173f6c`、操作蓝 `#1b67a8`、辅助青 `#1ba3b9`。
- 东航红与红橙渐变用于品牌和内页主 CTA；删除/危险状态使用红色语义，不作为普通数据色。主 CTA 实现为 `linear-gradient(96deg, #cb1e36, #e2603a)`，危险状态为 `#9c3030`。
- 页面标题 30px；内页工作台正文基准 16px，表格正文 15px，表头 14px；辅助文字 14–15px。
- 基础间距 8px；面板圆角 12px；标准按钮和工具栏输入框高度 40px，搜索输入内层 38px，表格紧凑操作 32px。
- 页面结构：固定品牌顶栏 76px、固定内页侧栏 248px、内容区最大宽度 1680px（单页内容列最大 1580px）。

## 页面约定

- 营销总览以五项指标、生命周期和活动状态为主，收入与 ROI 没有归因时显示真实的“等待回流”。
- 机会工作台按“洞察智能域 / 机会清单 / 洞察信号 / 运行记录”切换，列表、详情和 Agent 运行状态沿用现有数据。
- 活动中心按“活动清单 / 编排运行”切换；查看、编辑、删除和版本详情继续使用既有业务操作。
- 表格使用浅色表头、清晰行分隔和局部横向滚动；空状态、运行中和失败状态保留文字说明。

## 响应式

- 1180px 以下：总览和机会页面改为单列，指标卡改为三列。
- 820px 以下：侧栏收起为悬浮导航，主内容铺满窗口，页头左侧为折叠标签预留 40px 以上安全区。
- 560px 以下：隐藏全局搜索，指标卡改为单列，生命周期轨道支持横向滚动，页头面包屑省略显示。
